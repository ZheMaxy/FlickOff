# FlickOff

**Keep your Mac. Lose the flicker.**

**Исправный в остальном MacBook не должен раздражать из-за одной мерцающей полоски.**

Вечер, приглушённый свет, вы работаете за ноутбуком. Touch Bar снижает яркость —
и начинает мигать. Маленькая OLED-полоска над клавиатурой постоянно отвлекает,
хотя сам MacBook вполне устраивает.

Самое неприятное: **в macOS нет отдельного ручного ползунка яркости самого
Touch Bar.** Система регулирует её автоматически. А кнопки яркости *на* Touch Bar
управляют основным экраном — не той полоской, которая мерцает.

Когда следующий вариант — платить за аппаратный ремонт, хочется сначала
попробовать простое программное решение.

**FlickOff позволяет зафиксировать более высокую яркость или
полностью погасить дисплей панели — прямо из строки меню.** Для повседневного
использования не нужны команды в терминале, права администратора или остановка
системных служб.

На M1 MacBook Pro автора мерцание возникает на низкой яркости, а более высокая
фиксированная яркость помогает его обойти. Приложение не ремонтирует панель и
не обещает устранить любое мерцание. Оно даёт способ не попадать в проблемный
диапазон яркости или оставить дисплей выключенным, пока вы решаете вопрос с
ремонтом.

## Скачать

[Публичная бета для Apple silicon](https://github.com/ZheMaxy/FlickOff/releases).
Распакуйте архив, перенесите **FlickOff.app** в Applications и запустите.
Первая версия проверена на M1/macOS 27.2. Подпись локальная, notarization нет;
порядок первого запуска описан в [установке](INSTALL.md).

## Использование

- **Manual** — фиксированная яркость. Начните с высокой и найдите комфортный
  уровень без мерцания. **0% — минимальная яркость включённой панели, а не Off.**
- **Auto** — автоматическая регулировка macOS.
- **Off** — дисплей Touch Bar остаётся выключенным, пока работает приложение.
  Сенсорные нажатия и Touch ID при этом не отключаются.
- **Don't dim when idle** — не давать панели тускнеть и гаснуть от бездействия.
  Приложение не включает её при закрытой крышке, сне или блокировке экрана.
- **Launch at login** — запуск после входа в учётную запись.

При первом запуске выбраны Manual, 100% и предотвращение затемнения.
Постоянно включённый OLED может быстрее выгорать и потреблять больше энергии.
Используйте минимальную стабильную яркость или Off.

При обычном выходе восстанавливаются настройки яркости, которые были до запуска.
После аварийного завершения восстановление не гарантируется. Для возврата к
системной регулировке можно открыть приложение, выбрать Auto и выйти штатно.

## Совместимость и сборка

Целевая платформа — MacBook Pro с Apple silicon и Touch Bar. Аппаратные тесты
прошли на M1 13″ 2020 (`MacBookPro17,1`) с macOS 27.2; M2 пока не проверен. Минимальная версия
для сборки и запуска — macOS 13. Это не обещание совместимости приватных API на
всех версиях: они проверяются при запуске. Intel в текущий релиз не входит.

Нужны Xcode или Command Line Tools со Swift 6.0+. Обновления обеспечивает Sparkle 2.10.1; при первой сборке он скачивается автоматически.

```sh
git clone https://github.com/ZheMaxy/FlickOff.git
cd FlickOff
git config core.hooksPath .githooks
./build.sh
open build/FlickOff.app
```

Для постоянного использования перенесите приложение в Applications.
`./build.sh test` запускает тесты без изменения яркости; `./build.sh install`
пересобирает, заменяет установленную копию и запускает её.
Интерфейс пока на английском. [Установка](INSTALL.md) и
[решение проблем](TROUBLESHOOTING.md) описаны отдельно.

## Обновления

В меню есть **Check for Updates…** — проверка и установка обновлений прямо в
приложении. **Check for updates automatically** включает автоматическую проверку;
по умолчанию она выключена. Подписи Ed25519 защищают ленту и архив обновления.
Проверка обращается к GitHub; сбор системной статистики Sparkle отключён.
