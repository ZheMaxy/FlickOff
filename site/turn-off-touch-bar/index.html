How to turn off the Touch Bar on a MacBook Pro

macOS has no switch that turns the Touch Bar off. There are three ways to get a dark strip, and they differ in whether the display is really off, whether touches still do anything, and how long it lasts.

WayWhat you seeTouchesLasts
Empty it in System SettingsA black bar with no buttonsNothing to tapUntil you change it back
Stop its serviceOffUntested hereUntil sleep, logout or restart, at best
FlickOff's Off modeOff, and it goes dark again if macOS wakes itKeep working, invisiblyWhile the app runs

If what you're after is an end to flickering, read what to try when a Touch Bar flickers first. You may be able to keep using it.

Empty it in System Settings

This needs no app. It removes everything from the Touch Bar, as iDownloadBlog describes:

  1. Open System Settings → Keyboard → Touch Bar Settings.
  2. Set Touch Bar shows to Quick Actions, and turn off Show Control Strip.
  3. Set the option for pressing and holding the fn key to Show Quick Actions, turn off Show typing suggestions, and click Done.
  4. If Quick Actions still appear, go to Privacy & Security → Extensions → Touch Bar Quick Actions and uncheck everything.

You lose Esc, the function keys, and the brightness and volume controls. And because this only removes what's drawn on the panel, don't count on it to stop a panel that flickers. The names of these settings can vary between macOS versions.

Stop its service

Owners have scripted this with these commands:

sudo pkill TouchBarServer
pkill ControlStrip

macOS starts them again, so it doesn't stick: expect it back after sleep, logout or a restart, and possibly sooner. Stopping system processes also isn't something macOS expects you to do. It's a quick experiment rather than a setup to live with.

FlickOff's Off mode

FlickOff asks the Touch Bar's own service to turn the panel off, the way it does when idle, and turns it off again if something wakes it. Short flashes are still possible when that happens. It works from the menu bar, needs no administrator access, and comes back when you quit the app.

Touch input stays active, so the invisible keys still respond if you brush against them. Touch ID keeps working. If you need a Touch Bar that ignores touches completely, this doesn't do that.

FlickOff is for Apple silicon MacBook Pro. It's tested on the 13-inch M1 model, the M2 model isn't verified, and Intel models aren't supported.

Turn it off only when you're not using it

If you still want the Touch Bar while you work, FlickOff can leave it on and turn it off after 1, 5 or 15 minutes without keyboard or mouse input. It lights again when you come back. This also spares the OLED, which keeping it lit around the clock doesn't.

Questions

Can I remove or fully disable the Touch Bar?

Not with a setting. The ways above hide it or turn off its display. Touch ID is a separate sensor, and it keeps working in FlickOff's Off mode.

What about Esc and the function keys?

You can have them on the Touch Bar only while it's showing something, so with it emptied they're gone. In FlickOff's Off mode they still respond, but you have to find them by feel. An external keyboard solves this.

Will it come back after a restart?

With the settings it stays empty. With FlickOff, launch at login puts your choice back after you log in.
